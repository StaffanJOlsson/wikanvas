### Decisions taken within the docs (also in ARCHITECTURE §17.4)

- **Smoke step 4.** "Select all body text and delete it" cannot include the heading: step 15 expects the first heading
  of C's Markdown to be "Plan" from step 3, and step 4 types back only "quokka". The body is the paragraph under the
  heading; the step deletes its text and keeps the heading.
- **Smoke step 11, "the object is still there".** The frame API belongs to the host and has no global, and canvas
  pixels are fragile under SwiftShader. After the reload the server's board has one object, and the next save from
  the reloaded engine (a second rectangle) holds two, so the engine had the first.
- **Smoke step 13.** The export is fetched by the page (the browser's cookie and `Sec-Fetch-Site`), not by Playwright's
  request context with a hand-written header; the bare GET is checked to be refused.
- **Smoke step 1, "Home shows Getting started".** The seeded collection is in the sidebar of `/home`.
- **Step 9's fallback branch** is allowed only when `getContext('webgl2')` really fails in the browser; if the board
  falls back while WebGL 2 works, the test fails. It did not fall back.
- **Scenario 03** maps the goldens' ids instead of skipping the lookup-dependent goldens or regenerating them.
