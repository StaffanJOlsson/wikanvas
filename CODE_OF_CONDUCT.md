# Code of conduct

Wikanvas follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be respectful and constructive, and harassment of any kind is not accepted, in issues, pull requests, discussions and
any other project space.

To report a problem, contact the maintainer privately through GitHub
([@StaffanJOlsson](https://github.com/StaffanJOlsson)). Reports are handled confidentially, and the maintainer may
remove, edit or reject comments, commits, code, issues and other contributions that break this code, or block a
contributor, as the Covenant's enforcement guidelines describe.
